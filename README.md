Amazon Clone

A frontend Amazon-inspired e-commerce website created using HTML, CSS, and JavaScript. This project focuses on recreating the visual layout of an online shopping website and practicing frontend development concepts.


🚀 Features

~ Amazon-inspired homepage UI
~ Navigation bar with search section
~ Hero section with image slider
~ Left and right controls for changing hero images
~ Product category sections
~ Product cards with images and information
~ Basic product interaction using JavaScript
~ Shopping cart page/UI
~ Order summary section
~ Multiple shopping categories and product sections

-Using a Browser
-Clone or download this repository.

-Open index.html in a web browser.
-Using VS Code
-Open the project folder in VS Code.
-Open index.html.
-Run it using the Live Server extension, or open the file directly in your browser.
